# 팩트냥이 🐾 — AI 커닝 논란 팩트체크

2026년 11월 'AI 커닝' 논란(세무사·LEET·편입·국가자격시험 등)을 공식 자료·언론 보도 기준으로
**확정 / 조사중 / 의혹 / 거짓·해명됨**으로 정리한 모바일 우선 정적 사이트입니다.

- 라이브: https://kimcanal.github.io/factnyang/
- 외부 스크립트·웹폰트·CDN 없음. `index.html`을 그냥 열어도 동작합니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `data.js` | **모든 데이터** — 사건 카드(`FC_CASES`), 타임라인(`FC_TIMELINE`), 검정력 분석(`FC_POWER`), 수능 대책(`FC_SUNEUNG`), 마지막 확인 시각 |
| `app.js` | 화면 렌더링(홈·사건·타임라인·통계·정보, 바텀시트, 필터) |
| `mascot.js` | 오리지널 마스코트 '팩트냥이' SVG (판정별 표정) |
| `style.css` | 디자인 시스템(라이트/다크, 모바일·데스크톱) |

## 데이터 업데이트 방법
1. `data.js` 맨 위의 시각을 갱신합니다. 화면 상단 '업데이트' 배지와 홈 말풍선에 그대로 표시됩니다.
   ```js
   window.FC_UPDATED = "2026-11-17";            // 카드의 '마지막 확인일'
   window.FC_UPDATED_TIME = "2026-11-17 23:00"; // 상단 배지·홈에 표시 (KST)
   window.FC_TAKEAWAYS = [{h:"굵은 제목.", t:"한 줄 설명."}, ...]; // 홈 '오늘의 핵심 3줄'
   window.FC_TAKEAWAY_NOTE = {k:"내일 주목할 것", t:"한 줄."};     // 선택, 3줄 아래 메모
   ```
2. 사건을 추가·수정할 때는 `FC_CASES` 항목을 편집합니다.
   ```js
   { id:"고유-id", status:"확정|조사중|의혹|거짓/해명됨", type:"시험 유형", exam:"시험명",
     date:"YYYY-MM-DD", isNew:true, past:false,
     title:"제목", claim:"한 줄 주장",
     facts:["확인된 사실…"], counter:["반대 근거·당사자 해명…"],
     chart:{title, labels:[], values:[], unit:"명", hi:2, note}, // 선택
     sources:[["기사 제목","매체","날짜","https://…"]] }
   ```
   핵심 숫자(카드에 크게 보이는 값)는 `app.js`의 `KEY` 객체에 `id`로 추가합니다.
3. 타임라인은 `FC_TIMELINE`에 `["YYYY-MM-DD","내용","판정 또는 정책/예정"]`을 추가합니다.
4. 커밋 후 `main`에 푸시하면 GitHub Pages에 1~2분 내 반영됩니다.

## 편집 원칙 (반드시 지켜 주세요)
- **실명 금지**: 자백·유죄 확정이 아닌 사람은 '리트 전 영역 만점자'처럼 표기. 자백한 사람도 '세무사 수석 합격자 A씨'로만.
- **'○○냥이'를 확인 안 된 사람의 별칭으로 쓰지 않기.** 팩트냥이는 이 밈과 무관한 오리지널 캐릭터입니다.
- **의혹·조사중 카드에는 반대 근거와 당사자 해명을 함께** 싣고, 커뮤니티 캡처·개인정보는 싣지 않습니다.
- 모든 수치에는 실제로 열리는 출처 링크를 답니다.
